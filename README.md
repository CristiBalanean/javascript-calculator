# 🧮 JavaScript Calculator

A clean, responsive calculator built with vanilla JavaScript, HTML, and CSS — no frameworks, no dependencies.

🔗 **Live Demo:** [cristibalanean.github.io/javascript-calculator](https://cristibalanean.github.io/javascript-calculator/)

---

## Features

- Addition, subtraction, multiplication, and division
- Clean grid layout with responsive button design
- Clear function to reset calculations
- Lightweight — pure HTML, CSS, and JavaScript with zero dependencies

---

## Tech Stack

- **HTML** — Semantic markup and layout
- **CSS** — Grid-based button layout and styling
- **JavaScript** — DOM manipulation and calculation logic

---

## Getting Started

```bash
git clone https://github.com/CristiBalanean/javascript-calculator.git
cd javascript-calculator
```

Open `index.html` in your browser — no build step needed.

---
